# UI / 画面設計書 — 麻点論 (Matenron)

## 1. デザインシステム

### 1.1 カラーパレット

DESIGN.md で定義されたカラートークンを Tailwind CSS カスタムテーマとして適用する。

| トークン | 値 | 用途 |
|---------|-----|------|
| `primary` | `#004532` | メインブランドカラー (深緑) |
| `primary-container` | `#065f46` | ボタン・強調要素 |
| `on-primary-container` | `#8bd6b7` | プライマリコンテナ上テキスト |
| `surface` | `#f7faf6` | ページ背景 |
| `surface-container` | `#ecefeb` | カード背景 |
| `on-surface` | `#181c1a` | 本文テキスト |
| `tertiary` | `#652925` | アクセントカラー (赤系) |
| `error` | `#ba1a1a` | エラー表示 |

### 1.2 タイポグラフィ

| スタイル | フォント | サイズ | ウェイト |
|---------|---------|-------|---------|
| Display LG | Noto Sans | 48px | 700 |
| Headline LG | Noto Sans | 32px (モバイル: 28px) | 700 |
| Headline MD | Noto Sans | 24px | 600 |
| Body LG | Noto Sans | 18px | 400 |
| Body MD | Noto Sans | 16px | 400 |
| Label MD | Hanken Grotesk | 14px | 600 |
| Label SM | Hanken Grotesk | 12px | 500 |

### 1.3 角丸

| トークン | 値 |
|---------|-----|
| `rounded-sm` | 0.125rem |
| `rounded` | 0.25rem |
| `rounded-md` | 0.375rem |
| `rounded-lg` | 0.5rem |
| `rounded-xl` | 0.75rem |

### 1.4 テーマ

- ライトモード / ダークモード 切り替え対応
- OS の設定に追従し、手動で切り替え可能
- `ThemeProvider` で全画面に適用

### 4.2 ログイン / アカウント登録 (`/login`)

**目的**: 認証フォームを提供する。サインイン / サインアップをタブで切り替え。

**レイアウト**

```
┌──────────────────────────────────────────┐
│  [ヘッダー]                              │
├──────────────────────────────────────────┤
│                                          │
│        ┌──────────────────────┐          │
│        │  ログイン | 登録     │          │
│        │  ──────────────────  │          │
│        │  メールアドレス      │          │
│        │  [___________________]          │
│        │                      │          │
│        │  パスワード          │          │
│        │  [_______________][👁]          │
│        │                      │          │
│        │ ※登録時のみ:         │          │
│        │  パスワード(確認)    │          │
│        │  [_______________][👁]          │
│        │                      │          │
│        │  [ログイン / 登録]   │          │
│        └──────────────────────┘          │
│                                          │
└──────────────────────────────────────────┘
```

**フォーム仕様**

| フィールド | 表示条件 | バリデーション |
|-----------|---------|---------------|
| 表示名 | 登録時のみ | 1〜50 文字 |
| メールアドレス | 常時 | RFC 5322 形式 |
| パスワード | 常時 | 8 文字以上、英数字混合 |
| パスワード (確認) | 登録時のみ | 上のパスワードと一致 |

- パスワード入力欄には表示/非表示切り替えアイコンボタン (👁) を配置
- エラーはフィールド下に赤字でインライン表示
- 送信中はボタンをローディング状態にして多重送信を防ぐ

**コンポーネント**
- `SignInForm` (既存)
- `SignUpForm` (既存)
- `PasswordInput` — 表示切り替えアイコン付き Input

### 4.4 点数計算ツール (`/score-calculator`)

**目的**: 翻数・符・和了形式を入力して点数を計算する。

**レイアウト**

```
┌──────────────────────────────────────────┐
│  [ヘッダー]                              │
├──────────────────────────────────────────┤
│  点数計算ツール                          │
│                                          │
│  ┌────────────────────────────────────┐  │
│  │  翻数  [1][2][3][4][5][6+]         │  │
│  │  符数  [20][25][30][40][50]...      │  │
│  │  和了  ○ロン  ○ツモ               │  │
│  │  立場  ○親   ○子                  │  │
│  │                                    │  │
│  │  役を選ぶ (任意)                   │  │
│  │  [断么九] [平和] [立直] ...        │  │
│  │                                    │  │
│  │         [計算する]                 │  │
│  └────────────────────────────────────┘  │
│                                          │
│  計算結果                               │
│  ┌────────────────────────────────────┐  │
│  │  3翻 40符  → 満貫                 │  │
│  │                                    │  │
│  │  ロン                              │  │
│  │    子  → 7,700点                  │  │
│  │    親  → 11,600点                 │  │
│  │                                    │  │
│  │  ツモ                              │  │
│  │    親から → 3,900点               │  │
│  │    子から → 2,000点               │  │
│  └────────────────────────────────────┘  │
│                                          │
└──────────────────────────────────────────┘
```

**入力コンポーネント**

| コンポーネント | 種別 | 内容 |
|--------------|------|------|
| `HanSelector` | トグルボタン群 | 1〜13 翻 (役満含む) |
| `FuSelector` | トグルボタン群 | 20/25/30/40/50/60/70/80/90/100/110 |
| `WinTypeSelector` | ラジオ | ロン / ツモ |
| `PlayerTypeSelector` | ラジオ | 親 / 子 |
| `YakuMultiSelect` | チェックボックスグループ | 役を複数選択 (任意) |
| `ScoreResult` | 表示カード | 計算結果を内訳付きで表示 |

**UX 仕様**
- 入力変更に応じてリアルタイムで計算結果を更新 (デバウンス不要)
- 役満選択時は翻数・符のセレクターを無効化
- 結果カードは最初は非表示、計算ボタン押下後に表示

### 4.6 クイズ回答画面 (`/quiz/play`)

**目的**: 1 問ずつクイズを出題・採点する。

**認証**: 必須

**レイアウト (出題中)**

```
┌──────────────────────────────────────────┐
│  [ヘッダー]                              │
├──────────────────────────────────────────┤
│  問題                                    │
│  ┌────────────────────────────────────┐  │
│  │ 断么九・平和  子のロン             │  │
│  │ (2翻 30符)                        │  │
│  └────────────────────────────────────┘  │
│                                          │
│  この手は何点でしょう？                  │
│                                          │
│  ┌──────────┐ ┌──────────┐              │
│  │  3,900点 │ │  5,200点 │              │
│  └──────────┘ └──────────┘              │
│  ┌──────────┐ ┌──────────┐              │
│  │  7,700点 │ │ 11,600点 │              │
│  └──────────┘ └──────────┘              │
│                                          │
└──────────────────────────────────────────┘
```

**レイアウト (回答後)**

```
┌──────────────────────────────────────────┐
│  [ヘッダー]                              │
├──────────────────────────────────────────┤
│  ✅ 正解！  (または ❌ 不正解)           │
│                                          │
│  正解: 3,900点                           │
│                                          │
│  解説                                    │
│  ┌────────────────────────────────────┐  │
│  │ 2翻 30符                           │  │
│  │ 基本点: 240 × 4 = 960             │  │
│  │ 端数切り上げ → 3,900点            │  │
│  └────────────────────────────────────┘  │
│                                          │
│  [次の問題]  [クイズを終了]              │
│                                          │
└──────────────────────────────────────────┘
```

**状態管理**
- `idle` → `answering` → `answered` の 3 状態
- 選択肢ボタン: 選択前は通常表示、選択後は正解=緑・不正解=赤でハイライト
- 「次の問題」で同じ難易度の新問題を取得

## 6. レスポンシブ対応方針

| ブレークポイント | 幅 | 対応 |
|---------------|-----|------|
| モバイル | 375px〜 | 1 列レイアウト、ハンバーガーメニュー |
| タブレット | 768px〜 | 2 列グリッド |
| デスクトップ | 1024px〜 | 3 列グリッド、サイドバーなし |

- ヘッダーナビゲーションはモバイルでハンバーガーメニューに切り替える
- 選択肢ボタンはモバイルで 1 列 (縦並び)、デスクトップで 2×2 グリッド

## 7. ローディング / エラー状態

| 状態 | UI |
|------|-----|
| データ読み込み中 | `Skeleton` コンポーネントでプレースホルダー表示 |
| API エラー | `Sonner` (Toast) でエラーメッセージを通知 |
| 空データ | 「まだデータがありません」旨のメッセージ + CTA |
| 404 | 「ページが見つかりません」+ ホームへのリンク |

## 8. アクセシビリティ方針

- すべてのインタラクティブ要素にフォーカスリングを表示
- `aria-label` / `aria-describedby` を適切に付与
- カラーコントラスト比 WCAG AA (4.5:1) 以上を維持
- キーボードのみで全操作が可能であること
