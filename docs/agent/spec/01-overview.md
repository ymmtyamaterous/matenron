# 全体概要仕様書 — 麻点論 (Matenron)

## 1. プロジェクト概要

| 項目 | 内容 |
|------|------|
| アプリ名 | 麻点論 (Matenron) |
| ジャンル | 麻雀学習・ツール Web アプリ |
| 対象ユーザー | 麻雀を学びたいプレイヤー・実力を高めたいユーザー |
| 提供形態 | Web ブラウザ (レスポンシブ対応) |

### 1.1 目的

麻雀の点数計算を自動化するツールと、点数計算クイズを通じて楽しみながら麻雀のルール・役を学べるプラットフォームを提供する。

## 5. 認証・認可方針

- **認証方式**: メールアドレス + パスワード (better-auth)
- **セッション**: HTTP-only Cookie (`SameSite=None; Secure`)
- **保護ルート**: TanStack Router の `beforeLoad` で認証チェック、未認証なら `/login` へリダイレクト
- **API 保護**: oRPC ミドルウェアでセッション検証を行い、未認証の場合は 401 エラーを返す
- **パスワード要件**: 8 文字以上、英数字混合

## 6. 点数計算ロジック仕様

### 6.1 対応ルール

- **基本ルール**: 日本麻雀標準 (立直麻雀)
- **親/子**: 両対応
- **和了形式**: ツモ和了 / ロン和了

### 6.2 計算フロー

```
入力
  ├─ 役一覧 (複数選択)
  ├─ 符数 (30符, 40符, 50符 ... ドラ込みで自動計算も可)
  ├─ 翻数 (1翻〜役満)
  ├─ 和了形式 (ツモ / ロン)
  └─ 親 / 子

処理
  ├─ 基本点 = 符 × 2^(翻数+2)
  ├─ 満貫以上は固定点数テーブルを使用
  └─ 端数切り上げ (100点単位)

出力
  ├─ 子のロン: 支払い点数
  ├─ 親のロン: 支払い点数
  ├─ 子のツモ: 親支払い / 子支払い
  └─ 親のツモ: 子全員の支払い
```

### 6.3 役満・特殊役の扱い

| 種別 | 扱い |
|------|------|
| 役満 | 固定点数 (32000/48000) |
| 二倍役満 | 固定点数 (64000/96000) |
| 複合役満 | 加算対応 |
| 流し満貫 | 満貫として処理 |

## 7. クイズ機能仕様

### 7.1 出題形式

- 手牌の役・翻数・符を提示し、点数をユーザーが選択肢から選ぶ (4 択)
- 難易度: 初級 (1〜2 翻) / 中級 (3〜4 翻) / 上級 (役満含む)

### 7.2 採点ルール

| 結果 | ポイント |
|------|---------|
| 正解 | +10 pt |
| 不正解 | +0 pt |

### 7.3 ユーザー統計

- 総回答数
- 正答数 / 正答率
- 難易度別正答率

---

## 8. 役学習機能仕様

- 全役 (一般役 + 役満) を一覧表示
- 各役に以下の情報を掲載:
  - 役名 (日本語 / 読み仮名 / 英語名)
  - 翻数 (門前 / 食い下がり)
  - 概要説明
  - 成立条件
  - 例示牌 (テキスト表記)
